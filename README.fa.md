# وبو — Weboo ✨

[English](README.md) | [فارسی](README.fa.md)

**وبو** یک هایلایترِ خوش‌برخورد برای مرورگر شماست. هر متنی را در هر صفحه‌ای
انتخاب کنید، یکی از پنج رنگِ شاد به آن بدهید و اگر دلتان خواست یک یادداشت هم
کنارش بگذارید. همه‌چیز فقط روی **دستگاه خودتان** ذخیره می‌شود — بدون حساب
کاربری، بدون سرور، بدون ردیابی. هایلایت‌های شما مالِ خودتان است.

## چه کارهایی از دستش برمی‌آید؟

- 🖍️ **هایلایت** هر متنی با ۵ رنگ — مقاله، مستند، هر جا که مطالعه می‌کنید.
- 📝 **یادداشت** روی هر هایلایت (برای وقتی که می‌خواهید بدانید «چرا این را ذخیره کردم؟»).
- 🏷️ **برچسب مقاله** برای منظم نگه‌داشتن خواندنی‌ها.
- 📚 **داشبورد** که همه‌چیز یک‌جا جمع است: جست‌وجو، فیلتر رنگ/یادداشت/برچسب، مرتب‌سازی.
- 💾 **بک‌آپ** — کامل یا انتخابی (فقط بعضی سایت‌ها، مقاله‌ها یا برچسب‌ها) و بازیابی در هر زمان.
- 📤 **خروجی خواندنی‌ها** — کتابخانه‌ی Markdown برای ابسیدین، و کتابچه‌ی آماده‌ی چاپ (Save as PDF).
- 🌓 تم روشن و تیره، شمارنده روی آیکون افزونه، و فهرست «اینجا کار نکن» برای سایت‌ها.
- 🈯 برای خواندن فارسی و راست‌چین ساخته شده — و با صفحات چپ‌چین هم مهربان است.

## اطلاعات من خصوصی است؟

بله — کاملاً. وبو همه‌چیز را در حافظه‌ی محلی مرورگرِ خودتان نگه می‌دارد. هیچ
سروری در کار نیست، هیچ حسابی لازم نیست، آمارگیری هم وجود ندارد؛ هیچ چیزی از
کامپیوتر شما بیرون نمی‌رود. (حذف افزونه یعنی حذف داده‌ها — پس بک‌آپ فراموش نشود!)

## نصب (یک دقیقه)

1. فایل زیپ انتشار را بردارید: `dist/weboo-v<version>.zip` (فایل‌های قدیمی‌تر
   `dist/highlighter-extension-v<version>.zip` یادگارِ پیش از تغییر نام در
   v0.8.0 هستند). هر زیپ انتشار برای همیشه در `dist/` می‌ماند — تاریخِ
   انتشارِ پروژه‌اند و هیچ‌وقت پاک نمی‌شوند (سیاست).
2. آن را در یک پوشه باز کنید.
3. در کروم (یا هر مرورگر کرومیومی) به `chrome://extensions` بروید.
4. **حالت توسعه‌دهنده** را (گوشه‌ی بالا) روشن کنید، **Load unpacked** را بزنید
   و پوشه‌ی باز‌شده را انتخاب کنید.
5. تمام! متنی را انتخاب کنید تا نوار کوچک ظاهر شود. 🎉

> **نکته:** پوشه‌ی `extension/` در این مخزن «کد منبع» است. اگر همان را مستقیم
> بار کنید، کروم با خطای
> `Could not load options page 'dashboard.html'. Could not load manifest.`
> رد می‌شود — این طبیعی است و خرابی نیست. توسعه‌دهنده‌ها خروجی
> `.output/chrome-mv3/` را بار می‌کنند.

## استفاده

- **هایلایت:** متن را انتخاب کنید → نوار شناور → رنگ. منوی راست‌کلیک و کلیدهای میان‌بر هم کار می‌کنند.
- **یادداشت:** روی متن هایلایت‌شده کلیک کنید → دکمه‌ی ویرایش برای نوشتن یا تغییر یادداشت؛ دکمه‌ی حذف، هایلایت را برمی‌دارد.
- **بقیه‌ی کارها:** آیکون افزونه هایلایت‌های همین صفحه را نشان می‌دهد؛ آیکون چرخ‌دنده داشبورد را باز می‌کند — جست‌وجو، فیلترها، برچسب‌ها، بک‌آپ، خروجی‌ها، تنظیمات.
- **بک‌آپ:** داشبورد → «خروجی پشتیبان» برای فایل کامل JSON؛ «خروجی انتخابی» برای اینکه دست‌خود انتخاب کنید چه چیزی داخل فایل باشد. هنگام بازیابی می‌پرسد: ادغام یا جایگزینی کامل.
- **کتابچه:** داشبورد → «کتابچه» → مقاله‌ها را انتخاب کنید → چاپ یا Save as PDF.

## برای توسعه‌دهنده‌ها

کدبیس TypeScript + WXT + React است و صددرصد محلی. دستورهای کاربردی:

```bash
bun install
bun run build:wxt     # build توسعه → .output/chrome-mv3 (+ گیت parity)
bun run zip           # زنجیره‌ی کامل: typecheck-emit → build → parity → زیپ dist
bun run test          # مجموعه‌ی تست واحد (bun:test + happy-dom)
bun run lint          # eslint
bun run typecheck     # tsc --noEmit
bun run harness       # بازتولید هارنس E2E پاپ‌آپ
```

رگ‌های E2E با کروم واقعی (مسیر کرومیوم لازم دارند):

```bash
HLX_CHROME=<chromium> bun tests/e2e/real-theme-e2e.mjs    # چرخه‌ی تم پاپ‌آپ
HLX_CHROME=<chromium> bun tests/e2e/next-compat-e2e.mjs   # سناریوهای SPA/remount
HLX_CHROME=<chromium> bun tests/e2e/real-backup-e2e.mjs   # بک‌آپ انتخابی + داشبورد
HLX_CHROME=<chromium> bun tests/e2e/real-booklet-e2e.mjs  # انتخابگر/فهرست/فونت کتابچه
```

نسخه‌گذاری: هر تغییر با یک پله نسخه همراه است (رفع اشکال → PATCH، قابلیت →
MINOR، تغییر بزرگ → MAJOR)؛ نسخه در پنج جای هماهنگ زندگی می‌کند که چهار تای آن
با تست بسته شده است.

نقشه‌ی مخزن، اگر خواستید گشت بزنید: `entrypoints/` (نقاط ورود WXT)،
`extension/` (کد اصلی محصول)، `src/dashboard/` (داشبورد React)، `tests/`
(واحد + e2e). تصویر بزرگ در [معماری](docs/architecture.md) است، با
[لایه‌ی ذخیره‌سازی](docs/storage.md)،
[موتور لنگرگذاری](docs/anchor-engine.md) و
[بنچمارک‌ها](docs/benchmarks.md) کنارش.
